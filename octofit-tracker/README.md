# OctoFit Tracker

This repository contains a modern multi-tier OctoFit Tracker application.

## Structure

- `frontend/` - React 19 + Vite frontend
- `backend/` - Node.js + Express + TypeScript backend

## Ports

- Frontend: `5173`
- Backend: `8000`
- MongoDB: `27017`

## Getting Started

### Frontend

```bash
cd octofit-tracker/frontend
npm install
npm run dev
```

### Backend

```bash
cd octofit-tracker/backend
npm install
npm run dev
```

MongoDB should be available on `mongodb://127.0.0.1:27017`.
